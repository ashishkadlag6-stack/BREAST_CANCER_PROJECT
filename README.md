# Breast Cancer Prediction using Machine Learning

## Overview
This project is a Machine Learning based web application developed to predict whether a breast cancer tumor is **Malignant** or **Benign** using medical diagnostic features.

The application is built using **Python**, **Scikit-learn**, and **Streamlit** for an interactive user interface.

---

## Features
- Predicts Breast Cancer type
- Interactive Streamlit Web App
- User-friendly interface
- Machine Learning Classification Model
- Real-time prediction results
- Data preprocessing and model training included

---

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn

---

## Machine Learning Models
The project can include:
- Logistic Regression
- Random Forest
- Support Vector Machine (SVM)
- Decision Tree
- K-Nearest Neighbors (KNN)

---

## Dataset
Dataset used:
- Breast Cancer Wisconsin Dataset
- Available from Scikit-learn datasets
